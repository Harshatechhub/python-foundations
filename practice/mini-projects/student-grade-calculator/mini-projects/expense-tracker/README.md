# 💰 Expense Tracker

A beginner-friendly Python application for recording expenses and calculating total spending.

## 🎯 Objective

The goal of this project is to practice Python programming by building a simple real-world expense management application.

## ✨ Features

- Add expenses
- Store multiple expenses
- Display all recorded expenses
- Calculate total spending
- Menu-driven interface
- Exit the application safely

## 🛠️ Technologies

- Python 3
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements
- User Input
