# 💰 Expense Tracker

A beginner-friendly Python application for recording expenses and calculating total spending.

## 🎯 Objective

The purpose of this project is to apply Python fundamentals to a simple real-world problem: tracking personal expenses.

## ✨ Features

- Add expenses
- Store multiple expenses
- View all recorded expenses
- Calculate total spending
- Menu-driven interface
- Exit the application safely

## 🛠️ Technologies Used

- Python 3
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements
- User Input
