# 🧮 Student Grade Calculator

A beginner-friendly Python application that calculates a student's total marks, average, percentage, and grade for five subjects.

## 🎯 Objective

The purpose of this project is to apply Python fundamentals to a simple real-world problem.

## ✨ Features

- Accepts student name
- Accepts marks for 5 subjects
- Calculates total marks
- Calculates average
- Calculates percentage
- Automatically calculates the final grade
- Uses functions, lists, loops, and conditional statements

## 🛠️ Technologies Used

- Python 3
- Lists
- Functions
- For Loops
- Conditional Statements
- User Input

## 📊 Grading System

| Percentage | Grade |
|---|---|
| 90–100 | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| Below 50 | F |
